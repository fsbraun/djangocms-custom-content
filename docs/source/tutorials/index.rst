Tutorials
=========

Learn how to use djangocms-custom-content by following step-by-step guides.

These tutorials build upon each other progressively. Start with the first tutorial and work through each one in order:

1. **basic_setup** - Create a basic article model with versioning and admin interface
2. **article_with_plugins** - Extend your article model by adding CMS plugins and enabling URL routing via an app hook
3. **model_with_m2m** - Add many-to-many relations by creating a Person model and linking authors to articles

Each tutorial adds new functionality to the same article concept. You can follow them sequentially to build a complete, feature-rich content management system.
